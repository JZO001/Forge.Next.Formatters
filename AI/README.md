# The knowledge base of Forge.Next.Formatters

For AI sessions (and people) who continue the work on this package. `CLAUDE.md` in the repository root holds the rules;
this folder holds the background, so a new session does not have to rediscover it.

| File | What is in it | Update it when |
| --- | --- | --- |
| `HISTORY.md` | How the package evolved, what Zoltán asked for and decided, in order, with the reasons where they are recorded | Zoltán decides something, or asks for a change |
| `DESIGN.md` | How the package is built: the parts, the targets and their dependencies, one operation, the streams, the AES key material, the DI registrations, and why each design choice was made | The code's structure, the targets or the behaviour change |
| `VERIFICATION.md` | How to check the package (build, tests, the tests on a target the test project does not build for, the package contents), and what was run when, with the results | A check is run or a new one is added |
| `OPEN.md` | What is not done or not verified yet, and the questions waiting for Zoltán | An item is closed or a new one comes up |

Keep the files short and factual. Dates are absolute (2026-11-11, not "today"). Write in English.
